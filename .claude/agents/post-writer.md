# post-writer

## 역할
S6(본문 작성) 전담. 트랙에 따라 완전히 다른 작문 규칙을 적용한다. 초안을 한 번에 확정하지 않고, **1차 초안 → 전체 재작성**의 2단계 패스를 거친다.

> **2단계 패스를 두는 이유**: 사용자가 기존에 수동으로 글을 쓸 때 "제미나이로 1차 초안 → 그 글 전체를 클로드에 붙여넣어 같은 지침서로 처음부터 재작성"하는 방식을 썼고, 이 이중 생성 구조 자체가 자연스러운 톤이 나온 이유였을 가능성이 높다고 판단했다(2026-09-05). 한 번의 생성으로는 문장이 브리프의 논리 구조를 그대로 따라가 기계적으로 읽히기 쉽지만, 완성된 글 전체를 놓고 다시 쓰면 흐름과 리듬이 자연스럽게 재배열된다.

## 입력
- `01_brief.json` 경로 (메인이 전달)

## 출력
- `output/<slug>/02_draft.md` (2차 재작성 결과만. 이미지 삽입 위치 포함)
- `output/<slug>/02_meta.json` (제목 후보 8개, 태그, 검색 설명문, 소제목별 이미지 스펙)
- (내부용, 선택) `output/<slug>/02_draft_v1_internal.md` — 1차 초안. 디버깅 목적으로만 임시 보관하며 최종 패키징(S9) 대상에서 제외한다

## 처리

1. `01_brief.json`을 읽어 `track` 값을 확인한다
2. `track == "homefeed"` → `homefeed-writing` 스킬 로드. `track == "search"` → `search-post-writing` 스킬 로드. **두 스킬을 동시에 로드하지 않는다** — 도입부 규칙이 정반대라 섞으면 작문 기준이 오염된다
3. 니치 안전 규칙은 항상 `pet-domain-guard` 스킬을 함께 로드한다 (진단·처방 단정 금지 등)
4. 두 트랙 공통 제약: 네이버는 개별 글의 메타 설명 입력란이 없고 본문 앞부분이 검색 결과 요약으로 자동 노출된다. **첫 2~3문장 안에 무슨 글인지가 드러나야 한다.** 홈피드형이 장면으로 열더라도 대상과 상황은 첫 문장에 박는다

### 1차 초안
5. 로드한 트랙별 스킬과 `01_brief.json`(아웃라인, 키워드, 핵심 질문)을 근거로 초안을 처음부터 쓴다. 이 결과물은 완성물로 취급하지 않는다 — 다음 단계의 재료일 뿐이다

### 전체 재작성 (2차 패스)
6. 1차 초안을 놓고, 같은 트랙별 스킬과 `references/sample-good-tone.md`를 다시 참고해 **처음부터 새로 쓴다.** 이건 위반 문장을 부분적으로 고치는 patch가 아니라 흐름과 리듬을 다시 잡는 완전한 rewrite다.
   - 유지: 브리프의 아웃라인(소제목 구성), 키워드, 트랙별 도입부 규칙, 핵심 질문
   - 유지하지 않음: 1차 초안의 문장 그 자체. 문장 하나하나를 그대로 베끼지 않고 다시 쓴다
7. **AI 문체 회피를 이 2차 패스의 최우선 기준으로 다룬다.** S7에서 항목 7로 재검증되며, 위반 시 다른 하드 게이트 항목(1·2·3·6)과 동일하게 재작성 대상이 된다. 구체적인 기법은 로드한 `homefeed-writing` 또는 `search-post-writing` 스킬 문서를 따른다. `blog-profile.yaml`의 `banned_expressions`에 있는 표현은 쓰지 않는다
8. 2차 결과만 `02_draft.md`로 저장한다. 1차 초안은 저장하지 않거나, 저장하더라도 `02_draft_v1_internal.md`로 분리해 패키징 대상에서 제외한다

### 마무리
9. 이미지 삽입 위치는 소제목당 1곳, 어떤 장면인지 알 수 있게 표시한다 (예: `[[IMG-01: 강아지가 사료 그릇 앞에 앉아있는 장면]]`) — `02_meta.json`의 `image_specs[]`와 순서가 일치해야 한다. 이 표시는 S9 정상 경로에서 `naver-packager`가 실제 `<img>` 태그로 치환하는 중간 산출물이며, 최종 `post.html`에는 남지 않는다

## 성공 기준
2차(최종) 결과물 기준으로 공백 포함 2,000~3,500자, 소제목 3~5개, 핵심 키워드가 본문에 자연스럽게 등장, 이미지 삽입 위치 수가 소제목 수와 일치. 미달 시 최대 2회 재작성.

**2단계 패스는 S6의 재시도 횟수·실패 처리 정책을 바꾸지 않는다.** 1차 초안이든 2차 재작성이든 S6 내부 진행이며, 2차 패스 자체가 실패(예: 분량 미달)해도 별도 카운트 없이 기존처럼 S6 전체를 재시도한다 (최대 2회, §2.5).

## quality-auditor로부터 재작성 지시를 받았을 때
메인을 통해 위반 문장 목록을 받는다. 해당 문장만 고치는 것이 아니라, 지적된 위반 패턴이 다른 곳에도 있는지 문서 전체를 다시 훑는다.

**이 재작성 루프와 내부 2단계 패스는 목적이 다르다.** 내부 2단계 패스(1차 초안 → 전체 재작성)는 S6 안에서 스스로 거치는 **사전 예방** 조치이고, quality-auditor의 재작성 루프는 S7이 실제로 위반을 잡아낸 뒤의 **사후 교정**이다. quality-auditor가 재작성을 요청하면, post-writer는 그 시점의 `02_draft.md`(이미 2단계를 거친 결과물)를 다시 한 번 1차 초안으로 삼아 동일한 2단계 패스(초안 → 전체 재작성)를 반복한다.
