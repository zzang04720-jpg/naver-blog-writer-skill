# canva-visuals

## 트리거 조건
`visual-producer`가 S8(이미지 생성)에서 본문 이미지를 생성할 때.

## 범위 변경 (2026-09-05)
이 스킬은 원래 썸네일(브랜드 템플릿 필드 채우기)과 본문 이미지를 함께 다뤘다. 하지만 PIL 등으로 자동 생성한 결과물의 품질이 실제 캔바 수동 제작에 못 미쳐, **썸네일 자동화를 포기**했다. 이 스킬은 이제 **본문 이미지 생성 전용**이다.

썸네일 문구(`line1`/`line2`/`line3`/`sub`) 결정과 완성 파일 대기는 `.claude/agents/visual-producer.md`의 S8 절차를 따르며, 실제 제작은 사람이 사용자 소유의 캔바 템플릿 → 대량 제작에서 직접 한다. 과거의 썸네일 자동 생성 로직(브랜드 템플릿 필드 정의, 등록 시 안전 영역 보정 등)은 `thumbnail-compositor` 스킬로 옮겨 **폴백 전용으로 보존**했다 — 정상 흐름에서는 호출하지 않는다.

## 처리 (본문 이미지)
1. `02_meta.json`의 `image_specs[]`를 순회한다 (소제목당 1장)
2. 텍스트 없이, 해당 문단의 구체적 장면을 실사 스타일로 생성한다 (한글 텍스트를 이미지에 렌더링하지 않는다 — C6)
3. **실사 지시**를 반드시 적용한다: 렌즈 화각, 얕은 심도(배경 흐림), 자연광, 질감, 비연출 순간(포즈를 잡은 듯한 느낌 배제). 힉스필드 MCP도 실사 이미지 생성의 대안이다
4. `export-design`으로 1200px 이상 내보내 `images/`에 저장한다. 파일명: `<핵심키워드>-02.jpg`, `-03.jpg` ... (`-01`/썸네일 자리는 사람이 `thumbnail.jpg`로 채운다). 한글 파일명은 GitHub 업로드(S8.5) 시 URL 인코딩 문제를 일으킬 수 있으므로 ASCII 슬러그를 쓴다 (예: `<핵심키워드>`를 로마자 표기나 영문 슬러그로)

## 실패 처리
개별 이미지 단위로 1회 재시도한다. 재시도도 실패하면 해당 이미지만 스킵하고 `visual-producer`에 로그로 보고한다 — 이미지 1장이 빠져도 발행은 가능하므로 전체를 막지 않는다.

## 연결과 수동 대체

Canva MCP 연결과 사용 가능한 이미지 생성·내보내기 도구는 사용자 계정에서 확인한다. 특정 개인 템플릿이나 유료 플랜은 기본 제공하지 않는다. 연결이 없으면 문단별 이미지 요구사항을 사용자에게 제시하고, 사용자가 준비한 파일을 `output/<slug>/images/`에 넣은 뒤 진행한다. 도구가 없을 때 자동 생성됐다고 주장하지 않는다.
